# AGENTS.md 한국어판

`AGENTS.md`의 번역본입니다. 영어판이 정본입니다.

## 이 프로젝트가 무엇인가

AgentellIJ는 터미널에서 쓰는 AI 코딩 에이전트를 IntelliJ IDEA 안에서 띄웁니다.

대화, 판단, 도구 실행, 저장된 대화 기록은 에이전트 명령줄 도구가 가집니다. 플러그인은 그것을 보여주는
화면과 거기에 넣어주는 IntelliJ 정보를 가집니다. 플러그인은 대화와 에이전트 기록의 주인이 되지 않으며,
함께 들어 있는 웹 화면의 보관함에는 반드시 크기 제한과 오래된 것을 밀어내는 규칙이 있어야 합니다.

무언가를 쓰기 전에, 이 변경이 아래 중 무엇인지 먼저 말할 수 있어야 합니다.

- `host` — 화면을 제공한다
- `agent` — 에이전트 도구를 자원으로 관리한다
- `ide` — IntelliJ 상태를 읽거나 쓴다
- `bridge` — 플러그인과 에이전트 사이로 데이터를 나른다
- `config` — 설정을 저장한다
- `common` — 위 항목들이 쓰는, 아무것도 의존하지 않는 도우미

어디에도 해당하지 않으면 플러그인이 아니라 에이전트 도구의 몫입니다.

## 항상 지킬 것

1. 이 프로젝트가 무엇인지에서 벗어나지 않는다.
2. 계층 규칙을 지킨다. IntelliJ 없이 돌아갈 수 있는 코드는 `core`, 나머지는 `platform`이다.
3. 판단에는 테스트가 따른다.
4. 검증 명령을 돌리지 않고 완료를 주장하지 않는다.
